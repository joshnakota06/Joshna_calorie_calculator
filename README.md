# 🥗 Joshna Calorie Calculator

A colorful, high-contrast, animated beginner-friendly Python + Streamlit project.

## Features

- Age, height, weight and gender inputs
- Activity-level selection
- BMR calculation
- Estimated daily calorie requirement
- Simple interpretation
- Balloon animation
- Animated header and result card
- High-contrast readable text
- Mobile-friendly layout
- No database

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the Streamlit URL shown in the terminal, usually:

```text
http://localhost:8501
```

## Note

This calculator provides an estimate for educational purposes only and is not medical or professional nutritional advice.
